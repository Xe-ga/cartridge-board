# 📌 Пробковая доска для картриджей

Доска для коллекции игр: вешайте 3D-картриджи (Game Boy, GBA, DS, 3DS, Switch, PS Vita, PSP UMD, «домашние») по зонам «Хочу пройти», «Прохожу», «Пройдено», крутите их, наклеивайте свои обложки и ведите заметки по каждой игре.

**Открыть:** https://xe-ga.github.io/cartridge-board/

## Возможности
- 3D-картриджи с наклоном за мышкой, разные виды пластика (шероховатый, глянцевый, прозрачный, с блёстками, металлик)
- Эффекты: свечение, искорки, контурная аура, «парит»; наклейки — глянец, перламутр, голограмма, блёстки, золотая фольга, серебряный вихрь, призма, радужная фольга
- Полоска с логотипом консоли на этикетке (DS, 3DS, Switch), рельефные надписи на корпусах GB и GBA
- Две доски: пробковая и маркерная
- Карточка игры (правый клик по картриджу): вращение модели, «Об игре», блокнот с модулями-заметками
- Свои картинки на этикетки (кнопка или Ctrl+V)

## Где хранятся данные
Всё сохраняется **в вашем браузере** (IndexedDB) — у каждого посетителя своя доска, на сервер ничего не отправляется.
Чтобы перенести доску на другое устройство или сделать копию — кнопки 💾 (сохранить в файл) и 📂 (загрузить из файла).

## Управление
- Перетаскивание — переместить; колесо мыши или кружок ↻ — повернуть (Shift — шаг 15°)
- Двойной клик — внешний вид картриджа; правый клик — карточка игры
- Delete — снять с доски (Ctrl+Z — вернуть)
